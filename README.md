# QingZhou LocalTools · 轻舟离线工具箱

🌐 **Live Site**: https://qingzhou1204.github.io

Zero-install, 100% browser-local privacy utilities for finance, e-commerce, study notes, and AI Agent UX experiments.

2. [Offline Quote & Proforma Invoice Generator](https://qingzhou1204.github.io/tools/quote-generator/) — 离线商业报价单 A4 PDF 生成器
3. [E-Commerce 800x800 Image Compressor & SKU Profit Tool](https://qingzhou1204.github.io/tools/ecommerce-kit/) — 电商主图批压缩（含原生 ZIP 打包）+ SKU 利润核算

5. [Agent UI Spatial Co-Pilot Lab](https://qingzhou1204.github.io/tools/agent-ui-lab/) — Spatial direct-manipulation vs linear chat prototype
